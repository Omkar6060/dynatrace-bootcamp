# EasyTrade Field Guide

A container-yard-themed study site for the Dynatrace Associate bootcamp, live at **https://omkar6060.github.io/dynatrace-bootcamp/**.

- **`index.html`** (= `yard.html`) — the interactive container yard, the site's homepage. Click a container to open it.
- **`sidebar.html`** — a simpler sidebar/timeline version of the same content, kept as an alternate view.

Both are self-contained: no build step, no framework, just HTML/CSS/vanilla JS plus Google Fonts.

## The database: `data.json`

`yard.html` fetches `data.json` at load time — a plain export of the **Daily Tracker** Notion database (status, lab-done, assessment, per day). This is what makes the Notion table "the database" for the site:

- Each container's panel shows a live **Notion status badge** (Not started / In progress / Done), how many of its underlying days have their lab marked done, any assessment tied to it, and an **"open in Notion ↗"** link straight to that day's page.
- The progress bar and the little light on each container are separate — those track what *you've opened on the site itself*, saved to your own browser via `localStorage`. The Notion badge is the source of truth for actual bootcamp progress; the light is just a personal "have I looked at this" marker.
- If `data.json` is missing or can't be fetched (e.g. opened directly as a local file without a server), the site still works fully — it just won't show the Notion badges.

### Regenerating `data.json`

There's no live connection to Notion from the static site (a public page can't hold a Notion API token safely). Instead, `data.json` is regenerated by hand whenever the tracker changes:

1. Open the Daily Tracker in Notion, or ask Claude to pull the current rows.
2. Update the matching entries in `data.json` — each object is `{day, topic, status, labDone, sessionAttended, modulesDone, assessment, confidence, url}`.
3. Commit and push. GitHub Pages picks it up automatically.

The `DAY_TO_NODE` map at the top of `yard.html`'s script controls how Notion's "Day 01".."Day 14" rows fold into the site's containers (some containers, like `day1-2`, combine two Notion days into one box).

## Run it locally

```bash
python3 -m http.server 8000
# visit http://localhost:8000/
```

Opening `index.html` directly via `file://` works too, except the `data.json` fetch will silently fail (browsers block local `fetch()` by default) — serve it or use GitHub Pages to see the Notion badges.

To update: edit the files, then
```bash
git add -A
git commit -m "describe the change"
git push
```
GitHub Pages redeploys automatically within a minute or two of a push to `main`.

## Updating content

All step-by-step content lives in the `NODES` array near the top of `yard.html`'s script — one object per container, with `steps`, `code`, `concepts`, `brief` (practitioner module summary) and `links` (official Dynatrace docs). Add a new object to extend it; the yard, filters, and progress bar all pick it up automatically.
